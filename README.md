# Pennon Group Water Demand Analysis

## Overview
An independent analytical project examining per capita consumption 
and leakage performance across South West Water, Bristol Water 
and SES Water from 2019-20 to 2024-25.

## Data Source
Ofwat Water Company Performance Report 2019-25 (publicly available)

## Deliverables
- Power BI dashboard — PCC trends, leakage comparison, gap to 2050 targets
- Analytical report — key findings and strategic recommendations
- Stakeholder presentation — 7 slides
- Executive summary — one page
- Demand forecast table — Excel

## Key Findings
- All three companies tracking 36-38 l/p/d above the 110 l/p/d target
- SWW leakage at 107.8 Ml/day — nearly double the 2050 target
- SES Water requires priority demand reduction focus post-merger
